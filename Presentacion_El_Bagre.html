Enfoques de intervención

Mecánico

  • • Finito, predecible y controlable.
  • • Se aísla el elemento (se fragmenta).
  • • Modificación de una variable a la vez.
  • • Buscar "la pieza rota" y repararla.

Sistémico Complejo

  • • Infinito, dinámico, impredecible.
  • • Análisis centrado en interacciones.
  • • Considera efectos colaterales.
  • • Buscar patrones y oportunidades.

¿Reloj o Nube?

Problemas tipo Reloj

  • Repartir paquetes de comida.
  • Instalar paneles solares.
  • Comercializar un nuevo producto.
  • Realizar un proceso electoral.

Problemas tipo Nube

  • Garantizar seguridad alimentaria.
  • Combatir el cambio climático.
  • Construir un negocio sostenible.
  • Fomentar una democracia sana.

Qué implica una transformación

El sistema no se cambia desde afuera, ni se controla.

Pasamos de enfocarnos en "problemas" a entender cómo funcionan las relaciones hoy.

Pasamos de convencer o imponer a comprender, participar y adaptar.

No traemos "soluciones mágicas"; el cambio es un proceso, no un resultado fijo.
